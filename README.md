> **"Arrête de rêver sur Insta. Calcule la réalité du Mboa."**

**La Vraie Vie CM** est une plateforme interactive et communautaire conçue pour aider la jeunesse camerounaise à planifier ses projets de vie (logement, mariage, construction, business) avec des données financières réelles et actualisées.

---

## ⚡ Pourquoi ce projet ?
Au Cameroun, il est difficile d'obtenir des chiffres clairs sur le coût de la vie sans passer par des intermédiaires ou des estimations vagues. Ce site apporte une réponse **directe, chiffrée et interactive**.

## 🎨 Design Strategy : Neo-Brutalism
Nous avons choisi un style graphique **Banger** basé sur le Néo-Brutalisme :
* **Typographie massive** pour l'impact.
* **Contrastes forts** (Noir, Or, Vert, Rouge) pour l'identité nationale.
* **Interactions rapides** pour une expérience utilisateur moderne.

## 🚀 Fonctionnalités (Modules)
- [x] **Vivre Seul :** Simulateur de budget mensuel par quartier (Yaoundé/Douala).
- [ ] **Mariage Réaliste :** De la dot à la soirée de gala (Coming Soon).
- [ ] **Construire :** Estimation des matériaux et de la main d'œuvre (Coming Soon).
- [ ] **Lancer son Biz :** Coût réel de création de snacks, boutiques, etc. (Coming Soon).

## 🛠️ Stack Technique
* **Frontend :** HTML5, CSS3 (Neo-Brutalism style), JavaScript ES6.
* **Fonts :** Anton (Headings) & Space Grotesk (Body).
* **Hébergement :** GitHub Pages.

## 📦 Installation & Déploiement
Pour lancer le projet localement :
1. Clone le dépôt : `git clone https://github.com/ton-pseudo/la-vraie-vie-cm.git`
2. Ouvre `index.html` dans ton navigateur.

Pour déployer : Pousse simplement tes modifications sur la branche `main` de ton dépôt GitHub.
